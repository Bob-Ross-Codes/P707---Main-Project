# Sounds for the 1650 street scene

Export these from Soundly as WAV into the folders here, then commit and push.
Keep file names short (under ~40 characters, no commas): long Soundly names break git checkout on Windows. Keep each file under 100 MB.

| Folder | What is needed | Soundly search ideas |
|---|---|---|
| `Ambience` | 1 stereo loop, 1-2 minutes, quiet old-town background, no engines or traffic | "village ambience medieval", "town square quiet distant voices" |
| `Footsteps` | 6-8 single steps, leather shoe on stone or cobbles | "footsteps cobblestone leather", "footstep stone single" |
| `Talking` | 1 loop, 20-60 seconds, a man and a woman talking indistinctly outdoors | "walla small group", "conversation indistinct outdoor" |
| `Bell` | 1 distant church bell, a single toll or a few | "church bell single toll distant" |

- Footsteps: a recording of someone walking several steps is fine too; it gets cut into single steps.
- Talking: avoid clearly recognisable English words.

Do not import them into Wwise by hand. The events, 3D settings and SoundBanks are set up from these files afterwards.
